# Privacy policy

Azure Boards Modernizer does not collect, transmit, sell, or share personal information or Azure DevOps data.

The extension uses Chrome's synced extension storage only to retain these preferences: enabled state for `dev.azure.com`, theme, and density. It requests access only to `https://dev.azure.com/*` so it can apply local styles to supported Azure Boards pages. It does not use Azure DevOps APIs, analytics, remote code, cookies, or third-party services.

If this changes, the manifest, this policy, and the extension version will be updated before release.
